Risk rules

  • Size from the stop-loss distance, never from desired profit.
  • Do not widen a stop to avoid taking a loss.
  • Include spread, commission, slippage and swap where relevant.
  • Avoid blind entries into high-impact releases.
  • Stop trading when your own daily loss rule is reached.

This is a calculator, not a broker-connected risk guard. It cannot block trades in MT5.

Account & instrument

Data integrity contract

  • No feed is described as real-time unless the source provides verifiable current timestamps.
  • Price differences between broker feeds are normal; use the actual broker quote for execution decisions.
  • No prediction is guaranteed. BUY / SELL / NO TRADE requires verifiable inputs and a defined strategy.
  • No API keys, passwords, or broker credentials are stored by this app.
  • Account settings and checklist state are stored in this browser only.
